## Что это

ZeroKnowledge — self-hosted платформа для образовательных проектов. Она объединяет полноценную LMS, проверяемые задания, адаптивную практику, ИИ-помощника и инструменты администрирования в одном приложении.

Проект вырос из открытого LearnHouse и сохраняет его архитектуру и лицензию AGPL-3.0. В этой версии добавлены адаптивная практика, оценка знаний, генерация задач, ИИ-генерация курсов, блок рекомендаций на странице курса и перетаскиваемый ИИ-помощник.

### Для кого

| Роль | Что получает |
|---|---|
| **Студент** | Курсы, уроки, задания, автопроверка, персональная практика, повторения, ИИ-подсказки |
| **Преподаватель** | Конструктор курсов, задания, банк задач, проверка, аналитика, ИИ-генерация |
| **Администратор** | Пользователи, роли, доступы, статистика |

## Возможности от А до Я

### 1. Единое пространство

- Одна установка обслуживает один образовательный проект.
- Курсы, пользователи, задания и статистика находятся в общем пространстве.
- Публичные и приватные каталоги курсов.
- Приглашения, заявки на вступление, роли и права.

### 2. Пользователи и доступ

- Регистрация и вход.
- Парольный вход.
- Passwordless-вход по логину в development-режиме.
- MFA / TOTP и резервные коды.
- SSO для Enterprise-сборки.
- Управление сессиями и refresh-токенами.
- Роли: владелец, администратор, инструктор, студент.
- Группы пользователей и ограничение доступа к курсам.
- Аудит входов и действий.

### 3. Курсы

- Создание курсов вручную или через ИИ.
- Обложки, описание и теги.
- Публикация и снятие с публикации.
- Клонирование и экспорт/импорт курсов в ZIP.
- Программы обучения и треки.
- Главы, модули, порядок активностей.
- Черновики и предпросмотр.
- Доступ по ссылке, по группе или по оплате.

### 4. Уроки и редактор контента

- Блочный редактор в стиле Notion.
- Markdown и rich-text.
- Изображения, видео, embeds, файлы.
- Код, формулы, таблицы, callout-блоки.
- Видео с главами и субтитрами.
- Встроенные AI-блоки.
- Совместное редактирование через Yjs/Hocuspocus.
- Версии активностей.

### 5. Задания и автопроверка

Поддерживаются типы заданий:

| Тип | Проверка |
|---|---|
| `QUIZ` | Автоматическая, один или несколько вариантов |
| `CODE` | Запуск кода, видимые и скрытые тесты |
| `NUMBER_ANSWER` | Сравнение числа |
| `SHORT_ANSWER` | Проверка короткого ответа |
| `FORM` | Структурированная форма |
| `FILE_SUBMISSION` | Загрузка файла и ручная проверка |
| `CUSTOM` | Произвольный формат для внешних сценариев |

Возможности:

- Дедлайны и поздняя сдача.
- Несколько попыток.
- Проходной балл.
- Автоматическое выставление оценки.
- Скрытые тесты и защита от просмотра ответов.
- Подсветка ошибок и фидбек.
- Блок «Объясни решение» с проверкой понимания через ИИ.
- Защита от копирования и повторной отправки.
- Статистика по каждому заданию.

### 6. Банк задач

- Единый банк всех заданий.
- Фильтры по курсу, главе, типу, теме и уровню.
- Уровни сложности `1–3`.
- Оценка времени выполнения.
- Массовое редактирование темы/уровня.
- Привязка заданий к темам курса.
- Использование банка для адаптивной практики.

### 7. Адаптивная практика

Персональная лента задач для каждого студента.

- Освоенность темы `0..1`.
- Recency-weighted mastery: свежие попытки важнее старых.
- Half-life 21 день.
- Shrink-to-prior при малом количестве данных.
- Разная надёжность сигналов: код проверяется строже, ручная проверка мягче.
- Сложность задачи из фактического pass rate или уровня.
- Подбор задачи под целевой шанс успеха около **72%**.
- Слабые темы получают приоритет.
- Повторения по расписанию.
- Задачи «на вырост» для сильных студентов.
- Ограничение не более 2 задач на тему за день.
- Проверка prerequisite-тем.

Причины выбора видны студенту:

- `Новая тема`
- `Слабая тема`
- `Пора повторить`
- `На вырост`
- `Практика`

### 8. Оценка знаний

Для каждой темы и курса рассчитывается:

- mastery;
- confidence;
- количество попыток;
- дата следующего повторения;
- статус: слабо / в процессе / сильно / повторить.

Итоговая оценка:

| Балл | Оценка | Уровень |
|---|---|---|
| ≥ 90 | 5 | Эксперт |
| ≥ 75 | 4 | Уверенный |
| ≥ 60 | 3 | Ученик |
| < 60 | 2 | Начальный |
| нет данных | — | Без оценки |

Дополнительно показываются сильные темы, слабые темы и следующее рекомендуемое действие.

### 9. Блок «Задачи для вас»

На странице курса есть отдельный блок с персональной подборкой:

- `Рекомендовано` — новые и слабые темы;
- `Повторение` — просроченные повторения;
- причина выбора, тема, уровень и шанс решения;
- быстрый переход к исходному заданию;
- генерация дополнительной задачи через ИИ;
- обновление подборки.

### 10. ИИ-помощник

Плавающий помощник доступен на страницах курса.

- Понимает контекст страницы: курс, задание, активность.
- Подсказывает по задаче, не выдавая готовое решение без просьбы.
- Объясняет условие.
- Может добавить новую задачу в курс.
- Проверяет объяснения решений.
- Кнопку помощника можно перетаскивать по экрану; позиция сохраняется.
- Панель открывается рядом с кнопкой.

### 11. ИИ-генерация курсов

Полный цикл:

1. Пользователь описывает курс.
2. ИИ формирует структуру: название, описание, главы, уроки.
3. План можно итеративно менять.
4. Финализация создаёт реальные `Course`, `Chapter` и `Activity` в БД.
5. Дальше можно генерировать контент отдельных активностей.

### 12. Генерация задач через ИИ

`POST /api/v1/practice/generate`:

- выбирает weakest topic студента;
- генерирует quiz-вопрос;
- проверяет 4 варианта и ровно один правильный ответ;
- создаёт обычную задачу в опубликованном assignment;
- задача сразу попадает в адаптивную ленту.

## Быстрый старт

### Требования

- Bun `1.4.x`
- Python `3.14.7–3.14.8`
- PostgreSQL 16 + pgvector
- Redis 7+
- Docker — для runner/collab/e2e (опционально)

### 1. Зависимости

```bash
cd apps/web && bun install
cd ../api && uv sync
cd ../collab && bun install
```

### 2. Переменные окружения

Минимально:

```env
LEARNHOUSE_SQL_CONNECTION_STRING=postgresql://learnhouse:learnhouse@127.0.0.1:5432/learnhouse
LEARNHOUSE_REDIS_CONNECTION_STRING=redis://127.0.0.1:6379/0
LEARNHOUSE_AUTH_JWT_SECRET_KEY=change-me-to-a-long-random-string
LEARNHOUSE_DEVELOPMENT_MODE=true
LEARNHOUSE_TENANCY=single
LEARNHOUSE_DOMAIN=localhost:3000
LEARNHOUSE_FRONTEND_DOMAIN=localhost:3000
```

### 3. API

```bash
cd apps/api
uv run uvicorn app:app --host 127.0.0.1 --port 9000 --reload
```

### 4. Web

```bash
cd apps/web
bun run dev
```

### 5. Коллаборация

```bash
cd apps/collab
bun run dev
```

Откройте `http://localhost:3000`.

## ИИ и генерация курсов

Для ИИ-помощника, проверки объяснений и генерации курсов:

```env
LEARNHOUSE_IS_AI_ENABLED=true
LEARNHOUSE_AI_PROVIDER=<provider>
LEARNHOUSE_AI_BASE_URL=<provider-base-url>
LEARNHOUSE_AI_API_KEY=<provider-key>
LEARNHOUSE_AI_MODEL_FAST=<model>
LEARNHOUSE_AI_MODEL_STANDARD=<model>
LEARNHOUSE_AI_MODEL_PRO=<model>
```

### Проверка генерации курса

```bash
POST /api/v1/ai/courseplanning/start
POST /api/v1/ai/courseplanning/finalize
```

`start` возвращает поток с планом. `finalize` сохраняет курс, главы и активности в БД.

## Безопасность

- JWT access/refresh-токены с ротацией.
- Refresh-токены одноразовые.
- Проверка прав на каждом ресурсе.
- CSRF-защита.
- Ограничение размера запросов.
- Rate limit для логина и AI.
- MFA.
- Скрытые тесты не отдаются студенту.
- AI-провайдеры получают только необходимый контекст.
- Для локальной разработки можно включить passwordless admin, но **никогда** не включайте это на публичном сервере.
